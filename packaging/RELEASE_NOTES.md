## Что изменилось

- **Компьютеры находятся автоматически** в локальной сети через Bonjour/mDNS. Откройте новую версию на обоих ПК и выберите нужное имя.
- **Без ввода PIN и длинного отпечатка.** При первом подключении сверьте короткий код на двух экранах: владелец нажимает «Разрешить», клиент — «Код совпал». Ключ запоминается; его замена требует новой проверки.
- **Права выбирает владелец:** просмотр, клавиатура/мышь, звук, буфер обмена и файлы. «Прекратить сеанс» отзывает доступ и освобождает ввод.
- **Видео по защищённому TCP по умолчанию.** Клиент открывает исходящие соединения к хосту; отдельные входящие UDP-порты для FFmpeg больше не требуются. SRT остаётся дополнительным режимом.
- **Окна появляются сразу**, ещё до кадров, с состоянием ожидания. Если изображения нет, приложение показывает причину вместо скрытого ожидания. Ошибки захвата также передаются клиенту.
- Если поиск недоступен, для новой версии достаточно ввести IP и порт: ключ получается без отправки паролей, а соединение подтверждается тем же коротким кодом.
- Сохранены настройка 1–8 экранов, назначение локальным мониторам, портрет/Retina и исправление ошибки Windows 10013 с подбором доступного порта.

**Обновите оба компьютера до {{VERSION}}.** Подтверждение кодом и TCP-видео требуют новой версии на источнике. Интернет-сервер пока отложен; этот выпуск работает в локальной сети/VPN с прямой доступностью устройств.

## Перед первым запуском

Это пилотная версия без доверенных подписей Apple Developer ID / Windows Authenticode и без нотарификации Apple. Разрешения на запись экрана, ввод и выбранное аудиоустройство выдаются обычным способом в настройках ОС. Установка сама не запускает общий доступ.

Приложение передаёт существующие экраны хоста; новые виртуальные дисплеи в ОС не создаются. **240 FPS — настраиваемая цель**: фактические захват, показ, звук и задержка зависят от оборудования и требуют измерений на реальных компьютерах.
